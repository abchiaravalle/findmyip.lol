What we don't know about you

  • No logging The /api/ip Function reads CF edge data and returns it. No database, no log line we keep.
  • No IP-intel vendors ipinfo, MaxMind, ipapi, ipwho, ipify — none of them see your address.
  • No cookies Not by us, not by Cloudflare for this site. Nothing to consent to.
  • No analytics No Google, no Plausible, no Fathom, no Cloudflare Web Analytics.
  • No fingerprinting We don't read your browser fingerprint or build a profile on you.
  • 3 domains, that's it findmyip.lol, uselessfacts.jsph.pl, and tile.openstreetmap.org (only if you view the map).
  • Email is opt-in /api/send only fires if you click the button. Disclosed up front — SMTP2GO keeps standard delivery logs.
  • Cloudflare hosts this CF's standard edge access logs exist — same as for any hosted site. We add nothing on top.
  • Verify it yourself Open DevTools → Network tab. Reload. Count the requests. Read the source.
